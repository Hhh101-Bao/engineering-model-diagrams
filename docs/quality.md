# 质量标准与当前验证范围

## 对标与特点

对照 PlotNeuralNet 的FCN-8及neural-netz的U-Net原生示例，保留立体特征体积、尺寸/通道标注、连续卷积与长跳连。原图部分紧叠/重叠表达不作为本项目默认：独立操作留真实空隙，组内重复子层分离，端口接到首/末实体，避免看起来融成一块。另加入出处、未知信息、五套语义主题、真实GLB和渲染后审查。

参考：[PlotNeuralNet](https://github.com/HarisIqbal88/PlotNeuralNet)、[neural-netz](https://github.com/edgaremy/neural-netz)。第三方示例图不随本仓库复制分发。

## 实查项目

- 图库14个模型与14个模块/子网络均实际编译并查看PNG；另实际渲染5套同结构配色。
- PDF物理宽度、非空文本最小字号、栅格图像数、SVG的image元素和文字重叠候选见export-audit.json。文字宽估计采用Arial/Helvetica度量，仍需视觉复核。
- GLB逐个检查真实XYZ坐标、非共面顶点和三角面，不允许图片贴图；见runtime-audit.json。
- 分离重复层在DOWN方向的端口已用实际子体积轮廓校验并真实编译；宽度轴concat已保留axis2并通过编译。
- 五套主题使用同一图结构和几何，配色切换不修改模型拓扑。
- STANet经过独立助手按固定官方代码和原论文拆解。发现PAM残差、距离/插值顺序和末阶段重复次数差异，均在条目范围及IR中保留说明。

## 需要保留的边界

这些是阶段/模块级重绘，不代表已训练对应模型或复现论文指标。分组、示意比例、示例输入与省略细节逐项说明。长网络在较宽纸面验收，不能直接缩到窄栏后仍宣称字可读；必要时拆总图和模块图。

Windows实际执行过编译和便携依赖测试。Linux/macOS需要自行安装相应Typst/Poppler及字体；本轮未逐平台实测。离线三维查看器代码和网格文件经过检查，浏览器交互尚未完成实测，不将文件验证冒充旋转/缩放UI验收。

助手对任意新论文的理解不能保证零误差。来源存在、代码编译和测试通过不能证明其科学语义正确；必须回查图、公式和实现，对关键歧义保留待确认项。
