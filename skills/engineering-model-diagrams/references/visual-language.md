# 按模型语义组织图形

先确定读者应看清的结构：空间尺度、token交互、查询与记忆、门控、跨时相差分或相似度。再选择几何和布局。不要给所有模块换色后排成同一套立体积木。五套配色保留为用户选项；同一图优先使用两至三种有明确含义的颜色。

## 表达选择

| 对象 | `visual.glyph` | 布局要点 |
|---|---|---|
| 空间特征与卷积 | `tensor` | 尺度和通道随真实维度变化；连续卷积分段、独立操作留白 |
| 图像划分与窗口 | `patches` / `windows` | 在空间面表达分区；Swin移位用`shifted: true`，不把窗口画成通道数 |
| token / 嵌入向量 | `tokens` / `vector` | 用薄实体序列，省略号表示采样；标注真实N×D，不能把示意单元数当真实数量 |
| 相似度或注意力矩阵 | `matrix` | 明确行列意义；无数据不画伪造热力值。CLIP的`diagonal: true`只表示配对位置 |
| 多尺度输出集合 | `pyramid` | 四级几何只用于来源明确的四级集合，必要时展开为独立特征节点 |
| SAM候选掩码 | `masks` | 三个分离的掩码实体，限来源明确为三候选的SAM语境 |
| 抽象处理步骤 | `operation` | 低调的薄实体，与数据张量区分；不凭名字编造内部结构 |
| 加法和逐元素乘法 | `operator` | 简单清楚的数学符号，不画发亮球体或装饰图标 |

图形均由实际三维顶点组成。论文图是这些几何的轴测投影；源自`parts`的token、窗口和矩阵单元也进入GLB，不用图片纹理。算子符号与说明文字是标注，不需要强行雕成立体物体。

新IR可写：

```json
{"id":"embeddings","op":"custom","label":"Patch embeddings","axes":"tokens","shape":[197,768],"shapeStatus":"stated","visual":{"glyph":"tokens","cls":true},"evidence":["method"]}
```

`visual`只影响表达，不能替代`shape`、`op`、`params`或证据。脚本依据轴类型和已知算子选择基础图形；宿主助手应结合论文选择更贴切的几何、分组和布局。图库中的`catalog-profiles.mjs`是各条目的构图，不是新论文必须套用的模板。

## 减少模板感

- CNN看尺度级联，编码器解码器看对应层与跳连，Transformer看序列和窗口，DETR看queries与memory，遥感变化检测看双时相同尺度交互，CLIP看双编码器与行列配对。
- 总图与机制细节分开；能读出核心路径后再决定是否加展开图。重复模块写次数或括号，不把所有内部节点挤进总图。
- 注意力/残差机制图比较纵向公式流与分面板布局，不能把横向长链当作唯一形式。纵向布局也必须检查总高度；按期刊版面设置`render.maxHeightMm`，超限时拆图，不能只拟合宽度。
- 文字用技术名称、张量符号和必要参数。使用期刊栏宽和印刷字号判断留白，不靠大标题、口号、圆角卡片、阴影、渐变或三段式卖点填版面。
- 线条、字号和投影保持一致；模型之间的形态差异应来自结构。不要为了多样性随机变形、随机换投影或编造连接。
- 放大和按目标物理宽度两次查看PNG。检查窗口绘制顺序、遮挡、子层间距、矩阵行列含义与端口是否仍落在实体上。

参考结构语法：[ViT Fig.1](https://arxiv.org/abs/2010.11929)、[Swin Fig.3](https://arxiv.org/abs/2103.14030)、[CLIP Fig.1](https://arxiv.org/abs/2103.00020)。吸收其表示方式，不复制作者插图或装饰风格。
