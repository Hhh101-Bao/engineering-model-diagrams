# 体积网络图的视觉验收

此流程适用于特征张量、CNN、编码器解码器与多流网络。核心目标是几何表达模型结构。

1. **几何承载语义**：张量能看出正面、顶面与侧面。H/W 缩小时面尺寸缩小，C 增加时厚度增大；视觉比例允许压缩，但在同一图内保持单调一致，并明确标注尺寸。
2. **卷积组可见**：连续两到三次卷积绘成分段体积或成组叠层；激活可用 band 表示，不能把全部层压成相同矩形卡片。
3. **投影统一**：体积采用同一投影与深度方向。输入可为平面，Pool/UpConv具有独立颜色/窄层形状。透明层的遮挡关系与隐线需一致。
4. **布局表达结构**：编码端逐步缩小，解码端恢复；对应尺度跳连连接明确。多分支有清晰平行区域与汇合区。连接不穿越体积、维度标签或模块名。
5. **文字属于正确对象**：C 与空间分辨率标在对应轴或体积旁；模块名称单独排。算子名称与已知输出尺寸不能被静默省略。不要靠高分辨率预览掩盖最终尺寸下的细小字号。
6. **真实后端与可编辑源**：必须实际调用 PlotNeuralNet 的 TikZ 图元或 neural-netz/CeTZ。交付可重新编译的 .tex/.typ 及依赖、PDF/SVG和PNG。不得将旧卡片截图或平面图包装成立体后端结果。

这些后端输出三维张量的轴测矢量投影，常称2.5D。它们不生成可旋转的三维场景。只有生成并交付真实三维场景时才能声称后者。

审查时对照上游实际图，而不是仅比较颜色主题。上游基线分别为 PlotNeuralNet 的 FCN-8 与 neural-netz 的 U-Net。先达到体积、叠层与跳连表达，再讨论可读性与构图改进；自动检查通过不能替代视觉判断。

分离式图是默认：组内子层通过 sliceGap 留真实空隙，间隙至少大于斜投影深度再加0.55逻辑单位。池化等独立操作不得嵌入前一个体积。组间端口接到首/末子体积的真实表面，不接到组间空气中。连接须有可见线段和箭头；文字框之间保留余量，在目标物理尺寸检查，不能通过单纯缩小字体挤进版面。

科研配色与选择方法见 [五套科研主题](scientific-styles.md)。用户指定主题时保留其选择，不随机改变同类算子的颜色。
